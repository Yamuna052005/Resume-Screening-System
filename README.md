# Resume Screening System

## Description

An AI-powered Resume Screening System that evaluates candidate resumes against a given job description. The application analyzes textual content, identifies relevant skills, and computes a similarity-based match score to support faster and more consistent shortlisting.

## Tech Stack

### Backend

* Python
* Flask

 ### NLP Techniques

* TF–IDF Vectorization
* Cosine Similarity

### Frontend

* HTML
* CSS

## Key Features

* Automated resume text extraction
* Job description preprocessing
* Skill and keyword matching
* Resume–job compatibility scoring
* Simple and user-friendly interface

## How to Run
### Install dependencies
pip install -r requirements.txt

### Run the application
python app.py
