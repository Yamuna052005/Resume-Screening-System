#Resume Screening System

#Description
An AI-based resume screening system that evaluates resume against job description

#Tech Stack
-Python
-Flask
-NLP(TF-IDF,Cosine similarity)
-HTML,CSS

#Features
-Resume text extraction
-Job description preprocessing
-Skill matching
-Resume-job match score

#How to Run
pip install -r reuirements.txt
python app.py
